Ralexandria anatomy figures (Giovanni 2026-11-24, replaces Gray + Bassett of 2026-11-23): preferred originals are Gray's Anatomy 1918, Braune's atlas of frozen sections 1877 (Wellcome, Public Domain Mark) and the radiological images of the Visible Human Project (NLM, credit line in the caption). They are converted to the site style by code that uses no language model (tools/atlas_fetch.py, tools/atlas_build.py) and shown in the Atlas view and on entry pages where the figure title names the entry. Bassett (CC BY-SA 4.0) is no longer a preferred source.
