Giovanni 2026-11-21: in ultrasound, CT and MRI, two entries that are only two names for the same finding (no qualifier, same descriptors, e.g. low T1 signal / T1 hypointensity, low ADC signal / restricted diffusion) are merged as in X-ray: the old id stays readable through replaces and aliases, each pair is checked by a second model. Variants with a qualifier (focal / diffuse) stay separate (#92269e).
