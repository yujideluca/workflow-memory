Giovanni 2026-11-16: assume the specific descriptors (and finding names) are what the user is searching for, so the assistant cannot ask the user to choose them. Questions may use technical language to ask for descriptions of what is observed (cortex, long axis, echogenicity relative to liver), but must never suppose the user knows the term they are looking for: a bare term is never an answer option; the term is the tool's output after the user describes.
