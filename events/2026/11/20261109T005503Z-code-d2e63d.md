Radiology matcher goal (Giovanni 2026-11-08): NOT a clinical diagnosis tool and not a diagnosis ranker. It is a diagnosis ASSISTANT for the radiologist: from a loose description of a finding (e.g. a mass) it identifies the possible RADIOLOGICAL finding/category being described, proposes correct radiological terms, recommends compatible radiological findings, detects when the description is insufficient and asks the right questions so the structure gets properly described. Target 'right answer in top 3 at least 90%' applies to this finding-level task.
