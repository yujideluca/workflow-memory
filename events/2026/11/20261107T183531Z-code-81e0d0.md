Tests never build temp folders by hand (temp_dir()/name-PID, createTempDirectory): /tmp is RAM on the laptop and systemd clears it only after 10 days, and each rerun has a new PID, so leftovers pile up. Use the repo's self-deleting helper (status-quo crates/scratch.rs, pipeline-check tests/common Scratch, JUnit TemporaryFolder in QuizApp); any other temp-folder line must say 'scratch-ok:' and why, which each gate checks.
