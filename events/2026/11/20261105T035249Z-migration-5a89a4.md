To send Giovanni a message or file, run tg-send "text" or tg-send -f FILE [caption] on the Acer (bot @Claude_1123bot, one-way, only to Giovanni's saved chat; token in ~/.config/telegram-bot, never in memory). Files up to 50 MB. Telegram bots are not end-to-end encrypted: send no patient data. Unprompted messages need Giovanni's go-ahead per kind.
