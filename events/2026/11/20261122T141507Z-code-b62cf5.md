Spend tokens on purpose (Giovanni 2026-11-22): give each step to the cheapest level that can do it, read a briefing before any full text, end a session when its topic is done. Levels: (1) fixed repeatable step: script or command, no model; (2) lookup, search, logs, web pages, summaries: subagent model haiku; (3) work from a clear written spec (routine code, tests, wiki pages, checklist reviews): subagent on the default (sonnet, CLAUDE_CODE_SUBAGENT_MODEL in ~/.claude/settings.json); (4) design, root cause, medical facts, judgement: the main session, or model opus with the reason stated. A subagent gets a brief (goal, files, what done means), never the whole history; no fork for routine work. Context is paid again at every step: no whole large file, no second read of a file already in the conversation; after a finished topic record what is open and say that /clear is cheaper. A saving counts only when token-thrift report shows it in the total: measured 2026-11-22, 86 % of the cost sat in calls above 100k tokens of context, 39 % in subagents, 14.5 % in re-storing context after a pause; two earlier savings cut only the start-up text (under 2 %) because nothing measured the total.
