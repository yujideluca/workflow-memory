Giovanni 2026-11-15: a borderline list entry (between finding and diagnosis: scoliosis, hallux valgus, spondylolisthesis, atelectasis...) counts as a FINDING if it has at least one finding description that defines it (a defining imaging criterion). In some cases the description alone does not suffice and the user must take measurements on the image (angles, distances, grades); that requirement (what to measure and the criterion) must be stated whenever the finding is suggested. An entry with no defining imaging description is not a finding.
