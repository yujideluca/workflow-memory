Lesson of 2026-11-18 (Claude's own, not a rule from Giovanni): after pushing, read the CI result of that commit (gh run list -R OWNER/REPO -L 1) before reporting done. A test passed in the local gate only because it read the laptop's real ~/dev; CI was red for three commits unnoticed.
