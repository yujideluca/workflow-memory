Since 2026-11-18 mem forget, done, archive, reopen, claim and feedback refuse a reference that names no entry or that several entries share (harvester entries for the same key share their last segment; a promoted entry's reference starts with promo). The refusal lists the full names: repeat the command with the full name of one. Forget events written before that day for such references changed nothing.
